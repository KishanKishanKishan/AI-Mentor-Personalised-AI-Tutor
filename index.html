Python Loops & Iteration

This module was recommended because your assessment identified loops as a learning gap.

What is a loop?

A loop allows a program to repeatedly execute a block of code.

For Loop

A for loop is useful when iterating through a sequence. 

for i in range(5):
    print(i)

While Loop

A while loop executes while its condition remains true. 

count = 0

while count < 5:
    print(count)
    count += 1

Loop Control

The break statement stops a loop, while continue skips the current iteration. 

for i in range(10):

    if i == 5:
        break

    print(i)
